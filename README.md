# Dan Hajiya Investment — Official Company Profile Website

A modern, high-performance company profile and showcase landing page for **Dan Hajiya Investment (DAN HAJIYA INVESTMENT 19 LTD)**, a Nigerian commercial trading enterprise based in Kaduna.

## Overview

The site presents the company's background, confirmed leadership under Director **Umar Faruk Abubakar**, four core commercial trading divisions, real documentary selected work, and an authentic 32-asset media archive.

### Core Sections
1. **Introduction (Hero)**: Identity, Kaduna base, commercial trading proposition, and direct contact options.
2. **Company & Owner (About)**: Background, confirmed leadership, CAC incorporation status, and physical premises.
3. **What We Do (Activities)**: Four core business divisions (Automotive, Land Plots, Residential Homes, Telecommunications).
4. **Selected Work**: Documentary evidence of work (vehicle container loading, cargo vessel staging, warehouse walkaround, motorcycle demo).
5. **Complete Media Gallery**: 32 preserved manifest records (12 photos/graphics, 20 videos) across 7 categories.
6. **Process & FAQ**: Transparent 5-step commercial dealing flow and due diligence FAQ accordion.
7. **Company Details & Contact**: Confirmed contact channels, Kaduna registered office, and fraud prevention disclaimer.

## Tech Stack
- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: Tailwind CSS (semantic design tokens, dark charcoal & gold palette)
- **Icons**: Lucide React
- **Animations/Scroll**: React Scroll
